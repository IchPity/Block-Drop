Worum geht's?

Block Games ist ein eigenständiges Party-Spiel im Stil von Mario Party: bis zu vier Spieler treten in einer Serie aus Minigames gegeneinander an — Tastatur-Preset frei wählbar, gegen Bots oder gegen echte Freunde. Fehlende Mitspieler füllt die Lobby automatisch mit Bots auf, zwei lokale Menschen können sich auch einen Bildschirm teilen (Splitscreen).

Anmeldung läuft über denselben Account wie die Arcade-Website — oder einfach als Gast, dann aber nur gegen Bots (kein Online-Spiel, kein gespeicherter Fortschritt).

Installation

Zip entpacken und „Block Games (Demo).exe" starten — es ist kein Installer nötig. Windows zeigt beim ersten Start eventuell eine SmartScreen-Warnung („Unbekannter Herausgeber"), weil der Build nicht signiert ist — über „Weitere Informationen" → „Trotzdem ausführen" bestätigen.

Nur für Windows. Änderungsprotokoll und ältere Versionen gibt's auf GitHub.
