SCHACH.
MATT.

Klassisches Schach als Java-Desktop-App. Spiel lokal gegen einen Freund oder fordere ihn übers Netzwerk heraus — egal wo er ist.

⬇ Jetzt herunterladen Zurück zum Arcade
Benötigt Java 8+  ·  Windows / macOS / Linux  ·  Kostenlos
Features
♟
Vollständige Schachregeln
Alle Figuren mit korrekten Zügen — inkl. Rochade, En-passant und Bauernumwandlung.
🖥
Lokales 2-Spieler
Spiel direkt gegeneinander am selben Computer. Kein Account nötig.
🌐
Netzwerk-Multiplayer
Host als Server oder verbinde dich als Client über IP-Adresse und Port 5000.
♛
Bauernumwandlung
Wähle Dame, Turm, Läufer oder Springer wenn ein Bauer die letzte Reihe erreicht.
🔄
Spiel zurücksetzen
Jederzeit mit einem Klick ein neues Spiel starten — ohne Neustart der App.
⚡
Kein Install nötig
Einfach die JAR-Datei herunterladen und doppelklicken. Fertig.
So starten
In 3 Schritten spielbereit
Voraussetzung: Java 8 oder neuer muss installiert sein.
1
JAR-Datei herunterladen & in einen Ordner legen
2
Doppelklick auf Schach.jar — oder in der Konsole: java -jar Schach.jar
3
Für Netzwerk: Menü → Mehrspieler → Aktivieren, dann Server hosten oder als Client verbinden
